Just being silly with randomness!

The chain is generated by `builder.lua` from `source.txt`. It separates tokens into "words" (`[A-Za-z0-9]`) and "punctuation" (anything else), which just defines how they're collected and appended. The code is set to reject any words which don't appear at least four times (better for the larger, random-er dataset I have) and prune any connections between tokens that are less common than the average for that token (just to make it less noisy). `chain.lua` uses the `data` file generated by `builder.lua` to actually generate it, and isn't any different from a standard Markov chain traverser, other than picking an ending punctuation to stop at.

`source.txt` is taken from my [YouTube Posts archive](https://aadenboy.github.io/youtubeposts), with some text like transcriptions, links, and pings removed. Also, uncommon tokens are replaced with "fnord" as an ode to [Fungot](https://esolangs.org/wiki/Fungot).

Use `singlerun.lua` to do both building and generating in one run. Useful if you don't want to/can't serialize the tokens.
